DeviceBilinearFormIntegrator

Interface of bilinear form integrators evaluated on the device.

Defined in Rodin/Kokkos/Variational/Integral.h

template <
  class Backend>
class DeviceBilinearFormIntegrator;
Template parameters
Backend Kokkos backend of the mesh context.

Contents

  • Reference
    • Public types
    • Public functions

Assembly::Kokkos discovers this interface on the local integrators of a bilinear form and asks each one for its contributions as device triplets. An integration is a call to prepare(), which locates the entries of the cells, followed by fill(), which writes them.

Tells whether the entries vanish off the diagonal of the component blocks, so that prepare() can list the diagonals only.

Returns Whether the local matrices are diagonal by component blocks.

size_t prepare(bool diagonal) const pure virtual

Locates the entries of every selected cell.

Parameters
diagonal Whether to list only the entries on the diagonal of the component blocks, honored when isBlockDiagonal(). Integrators with equal layouts prepared with the same honored choice list the same coordinates in the same order.
Returns Number of entries.

size_t getSpacing() const pure virtual

Gets the spacing of the entries located by the last call to prepare().

Returns Spacing given to getEntryPosition().

void fill(const ::Kokkos::View<Real*, MemorySpace>& values, size_t offset, Real sign, bool accumulate, const ::Kokkos::View<Index*, MemorySpace>& rows, const ::Kokkos::View<Index*, MemorySpace>& cols) const pure virtual

Integrates the form over its region.

Parameters
values Entry values, the entry of rank r being written at offset + getEntryPosition(r, count, getSpacing()).
offset Position of the first entry.
sign Factor of the contributions.
accumulate Whether the contributions are added to the values instead of replacing them.
rows Row indices, test degrees of freedom, written as the values unless empty.
cols Column indices, trial degrees of freedom, written as the values unless empty.

The entries are the ones located by the last call to prepare().

TripletsType assemble() const

Integrates the form over its region into new triplets.

Returns Local contributions, with rows indexing test and columns indexing trial degrees of freedom, arranged as by fill() at offset zero.
