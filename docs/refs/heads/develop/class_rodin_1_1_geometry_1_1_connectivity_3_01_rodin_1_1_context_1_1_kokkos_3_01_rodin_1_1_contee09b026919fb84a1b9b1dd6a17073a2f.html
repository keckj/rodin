Architecture

Entity vertex lists are dimension-major resident arrays. Each incidence relation owns independent CSR arrays. compute() uses Rodin's recursive dimension-pair dispatch, device transpose and ordered intersection. Discovery emits reference subentities, sorts symmetric vertex keys, and scans first occurrences to preserve existing IDs and CPU discovery order. Vertex orientation is retained independently of the symmetric keys.

Only counts, allocation sizes and reference-cell constants cross the host boundary during computation; actual mesh topology remains resident. Legacy reference-returning queries materialize read-only host entries on demand. Mutation requires exclusive access and invalidates borrowed views and host references. Copies own independent resident arrays.
