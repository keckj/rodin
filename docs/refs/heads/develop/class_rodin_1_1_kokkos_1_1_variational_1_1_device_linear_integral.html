DeviceLinearIntegral

Device integration of a test operator over a region of a Kokkos mesh.

Represents

for a scalar valued operator of a scalar or vector device test function on a resident Kokkos mesh, such as or . The region is given by getRegion(). The operator is lowered once to DeviceView, then a kernel integrates every polytope of the region with one thread and writes its local vector as device entries.

A face is integrated with the basis of the face, whose degrees of freedom are the ones of the face, as on the host.

The quadrature order is selected on the host as by the generic QuadratureRule, once per reference geometry, as described in Internal::DeviceQuadrature.

The host evaluation interface (setPolytope(), integrate()) is not available and raises; the form is assembled by Assembly::Kokkos.

Rodin::Variational::Integral, BoundaryIntegral, FaceIntegral and InterfaceIntegral specialize this class for device spaces.

Integrates the polytopes of at most Vertices vertices.

Parameters
mesh Resident mesh.
polytopes Selected polytopes, located by prepare().
test Device view of the test operator.
dofs Device degrees of freedom of the test space.
vdim Vector dimension of the test space.
values Entry values.
offset Position of the first entry.
sign Factor of the contributions.
accumulate Whether the contributions are added to the values.
indices Entry indices, written unless empty.

When Exact, the space is P1, every polytope has Vertices vertices and the vector dimension is maximal, so the local loop has a static bound. Shape is the geometry tag of the integration points.
