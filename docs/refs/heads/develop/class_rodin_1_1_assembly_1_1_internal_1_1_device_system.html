DeviceSystem

Linear system assembled in device memory with value constraints eliminated, then copied to Eigen.

Defined in Rodin/Kokkos/Assembly/Kokkos.h

  class Backend>
class DeviceSystem;
Template parameters
Backend Kokkos backend of the mesh context.

The system is the one of the host assemblies up to rounding, since the integrators sharing a pattern sum their local matrices in place and the multithreaded host assemblies sum in an order that depends on the thread count. The nonzero entries of the local integrators, then of the global integrators, in rank order, followed by the entries of the preassembled forms make the list of matrix contributions. Rows of fixed degrees of freedom are dropped and become identity rows holding the fixed value, and the columns of fixed degrees of freedom move to the right-hand side. The contributions to every coefficient are summed in list order, as Eigen::SparseMatrix::setFromTriplets() sums duplicates, and products are rounded before being summed. The entries stay where the integrators store them, their list order following from their position, and only the compressed matrix and the right-hand side are copied to the host.

Identification constraints, from identification Dirichlet conditions and periodic conditions, are resolved on the host as in the host assemblies. Each contribution is then expanded on the device on the masters of its row and column, in rank order, the identified columns lifting their affine values to the right-hand side, and the identified rows become the rows of their constraints.

Typedef documentation

using Range = ::Kokkos::RangePolicy<ExecutionSpace, ::Kokkos::IndexType<Index>>

Range of the kernels, indexed by Index.

The default index of a Kokkos 5 range is the index_type of the execution space, a 32 bit int on the GPUs, and a bound past it aborts. One process can hold more than 2^31 entries.
