DevicePotentialIntegral

Device integration of a potential tested against a shape function.

Represents

for P1 trial and test spaces on a resident Kokkos mesh, with the quadrature of the host QuadratureRule. A thread integrates one pair of a selected test cell and a selected trial cell. A pair of coincident triangles is integrated by the Sauter-Schwab transformation with a tensor Gauss-Legendre rule, any other pair by the centroid rules of both cells.

The kernel is a KOKKOS_LAMBDA. For scalar spaces it takes the trial and the test points, as const Rodin::Kokkos::Geometry::PointView&, and returns a Real. For vector spaces it takes first a Rodin::Kokkos::Geometry::Matrix&, sized to the vector dimension and set to zero, which it fills.

The entries of a pair follow the entries of the previous pairs, the pairs being ordered by test cell, then by trial cell, as the host assemblies visit them.

The order of the Gauss-Legendre rule is read once, on the first triangle of the mesh, so it must depend only on the geometry.

The host evaluation interface (setPolytope(), integrate()) is not available and raises; the form is assembled by Assembly::Kokkos.
