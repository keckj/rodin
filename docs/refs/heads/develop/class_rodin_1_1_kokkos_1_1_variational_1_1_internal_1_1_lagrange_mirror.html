LagrangeMirror

Host copy of a resident mesh with the H1 spaces of degree K built on it.

Defined in Rodin/Kokkos/Variational/H1.h

template <
  size_t K,
  class Backend>
class LagrangeMirror;
Template parameters
K Polynomial degree.
Backend Kokkos backend of the mesh context.

Contents

  • Reference
    • Public types
    • Constructors, destructors, conversion operators

The host spaces number the degrees of freedom and answer the form language queries; the scalar numbering is copied to the device.
