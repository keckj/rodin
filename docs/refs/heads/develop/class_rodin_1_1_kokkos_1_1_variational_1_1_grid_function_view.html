GridFunctionView

Coefficients of a grid function of a device space in device memory.

Defined in Rodin/Kokkos/Variational/DeviceView.h

template <
  DeviceSpace FES>
class GridFunctionView;
Template parameters
FES Device space of the grid function.

Contents

  • Reference
    • Public types
    • Constructors, destructors, conversion operators
    • Public functions

The coefficients are copied to the mesh memory space when the view is built, so the view reflects the grid function at lowering time. The copy comes from the transfer cache of the mesh, which keeps it resident while the coefficients do not change. Values and derivatives are interpolated from the degrees of freedom of the polytope holding the point, as on the host.
