DeviceQuadrature

Quadrature tables of the polytopes of one dimension of a resident mesh, one formula per reference geometry.

Defined in Rodin/Kokkos/Variational/Integral.h

  class Mesh>

The quadrature order is selected on the host, once per reference geometry, using the first polytope of each geometry. It must therefore depend only on the geometry, which holds for meshes whose polytopes of a given geometry share one transformation degree. The reference coordinates are flattened and padded to three components.
