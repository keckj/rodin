template<class Values, class Indices, class TestIndices, class TrialIndices>
void writeEntries(const Values& values, const Indices& rows, const Indices& cols, size_t base, size_t spacing, bool accumulate, bool index, const TestIndices& testIndices, Index testStride, Index testComponents, const TrialIndices& trialIndices, Index trialStride, Index trialComponents, Index copies, bool compact, Index ntr, Index te, Index tr, Real v)

Writes an integrated entry of a local matrix and its copies.

Parameters
values Values of the entries.
rows Rows of the entries, written when index.
cols Columns of the entries, written when index.
base Position of the first entry of the polytope.
spacing Distance between consecutive entries of the polytope.
accumulate Whether to add to the values.
index Whether to write the rows and columns.
testIndices Global scalar test degrees of freedom of the polytope.
testStride Global distance between the components of a test degree of freedom.
testComponents Integrated test components per scalar degree of freedom.
trialIndices Global scalar trial degrees of freedom of the polytope.
trialStride Global distance between the components of a trial degree of freedom.
trialComponents Integrated trial components per scalar degree of freedom.
copies Copies of each entry on the diagonal of its block.
compact Whether to list the diagonal entries of the blocks only.
ntr Number of integrated trial indices.
te Integrated test index.
tr Integrated trial index.
v Integrated value.

The integrated entry (te, tr) stands for copies by copies entries of the local matrix: test index te * copies + t and trial index tr * copies + s hold the value when t equals s, zero otherwise. Local index a * vdim + r is component r of the scalar degree of freedom a, numbered globally as dof + r * stride, with vdim the product of the integrated components and the copies. The entry of local test index i and local trial index j has rank i * ntr * copies + j. When compact, only the entries on the diagonal of the blocks are listed, the copy t having rank (te * ntr + tr) * copies + t.

size_t getEntryPosition(size_t rank, size_t count, size_t spacing)

Finds where an entry of a device integrator is stored.

Parameters
rank Rank of the entry, the entries of each polytope following the entries of the previous polytope.
count Number of entries.
spacing Spacing of the entries, as given by the integrator.
Returns Position of the entry past the offset of the integrator.

When every integrated polytope owns the same number n of entries and there are M > 1 polytopes, entry j of the k-th polytope is stored at k + j * M and the spacing is M, so that the threads of consecutive polytopes write contiguous memory. Otherwise the spacing is one and the entries are stored in rank order.
