CG final

Jacobi preconditioned conjugate gradient on the device, for a system whose matrix is a Kokkos::SparseMatrix.

The iteration, the defaults and the stopping test are those of the sparse Eigen CG: the solve stops when , the default tolerance is the machine epsilon and the default iteration limit is twice the size. The matrix is read in place by Kokkos-Kernels; the right-hand side and the solution are copied between the host and the device at every solve, and the solution is used as the initial guess when its size matches.

Solves the linear system where is the matrix operator, is the solution vector, and is the right-hand side vector.

Initial guess contract

On entry, the system's solution vector holds the initial guess; on exit it holds the solution. Iterative solvers use the guess whenever it is correctly sized; direct solvers ignore it. Assembly seeds the guess from the trial function data, which is zero by construction unless set.
