Architecture

The mesh holds the shard of this process as a local resident mesh, the ownership of each of its entities, and a reference to the distributed host mesh it was built from. Every query is answered in the local numbering of the shard, which the kernels of a local resident mesh expect. The boundary, the interface and the measures are those of the distributed mesh: they are read from the host mesh, which owns the entities across processes.

The device view marks the entities this process owns. Integrators skip the others, so that each polytope is integrated once over the processes. The host mesh must outlive this mesh, and its shard must not change after this mesh is built.
