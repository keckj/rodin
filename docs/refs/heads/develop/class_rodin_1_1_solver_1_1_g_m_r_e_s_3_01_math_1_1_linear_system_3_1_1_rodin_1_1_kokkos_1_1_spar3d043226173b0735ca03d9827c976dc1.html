GMRES final

Restarted GMRES of Kokkos-Kernels on the device, right preconditioned by Jacobi, for a system whose matrix is a Kokkos::SparseMatrix.

The defaults are those of the sparse Eigen GMRES: the machine epsilon as tolerance on , twice the size as iteration limit and a restart of 30. The iteration limit is rounded up to a whole number of restart cycles. The matrix is read in place; the right-hand side and the solution are copied between the host and the device at every solve, and the solution is used as the initial guess when its size matches.

Solves the linear system where is the matrix operator, is the solution vector, and is the right-hand side vector.

Initial guess contract

On entry, the system's solution vector holds the initial guess; on exit it holds the solution. Iterative solvers use the guess whenever it is correctly sized; direct solvers ignore it. Assembly seeds the guess from the trial function data, which is zero by construction unless set.
