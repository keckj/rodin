IntegrationPointView

P1 basis values and physical gradients at one quadrature point.

Defined in Rodin/Kokkos/Variational/DeviceView.h

class IntegrationPointView;

Contents

The point is evaluated once per quadrature point and shared by every shape function of the integrand. Gradients are mapped to physical space by , as on the host.

A StaticGeometry tag evaluates the point with static bounds, getting the physical point and the Jacobian in one pass over the vertices.

void setPoint(const Geometry::PointView& point)

Moves the integration point within its polytope.

Parameters
point Point on the polytope of the current point.

The P1 map of a simplex is affine, so its Jacobian, distortion and basis gradients are kept and only the basis values are evaluated again. Other polytopes are evaluated again in full.
