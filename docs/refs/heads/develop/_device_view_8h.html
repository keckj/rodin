template<bool Reduce, class T>
auto getStored(const T& v)

Gets the value stored by a bilinear kernel.

Template parameters
Reduce Whether the kernel is component diagonal.
Parameters
v Basis value.
Returns Payload of v if Reduce, v otherwise.

A component diagonal kernel (IsComponentSparse values on both sides) stores the payload of the values of component 0 only: their inner product is the inner product of the payloads, and the payload is smaller, so more quadrature points fit the team scratch memory.

Variable documentation

template<class T>
bool IsComponentSparse constexpr

Tells whether a basis value type is sparse by component.

Template parameters
T Basis value type.

Values of these types come from the vector basis , scaled by scalars or multiplied on the right by vectors: the value of the scalar degree of freedom a and component r has its nonzero component or row at r, and its entries do not depend on r. The inner product of two such values vanishes across components and, within one component, equals the product of the values of component 0, so the bilinear kernels integrate one scalar matrix and replicate it on the diagonal of the component blocks. An operation producing these types keeps this property.
