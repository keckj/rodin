Architecture

The point owns its reference coordinates and borrows immutable entity data. Evaluation reproduces the source transformation, including nonaffine P1 tensor-product and rational pyramid geometry. Numerical results are values in fixed-capacity storage, requiring neither allocation nor shared mutable caches. At the pyramid apex the symmetric centreline derivative convention matches Rodin's host P1 basis.

PointView getCellPoint(Index cell) const

Carries a point of a face to an incident cell.

Parameters
cell Index of a cell incident to the face of the point.
Returns Same physical point, bound to the cell.

The cell reference coordinates interpolate, with the P1 basis of the face, the reference vertices of the cell at the vertices of the face. This is exact since every reference face is mapped onto the reference cell by an affine map.

void evaluateBasis(Index a, Real& value, Vector& gradient) const

Evaluates one P1 basis function and its first derivatives.

Parameters
a Local vertex index, ordered as the reference vertices.
value Basis value at the owned reference tuple.
gradient Reference gradient, sized to the reference dimension.

The basis coincides with Rodin's host P1 Lagrange basis, so it serves both as the geometric map of P1 meshes and as the P1 shape functions.
