Rodin/Kokkos/Assembly/PETSc.h file

Device assembly of PETSc problems on resident Kokkos meshes.

Contents

  • Reference
    • Namespaces
    • Classes
    • Functions

The integrators write their entries straight into coordinate lists in device memory, which PETSc consumes through MatSetPreallocationCOO and MatSetValuesCOO. The matrix and the vectors are created with the PETSc Kokkos types, so a solve on the device never copies the system to the host.
