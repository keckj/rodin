Represents

for vector device spaces, with the first Piola-Kirchhoff stress of the device law. The quadrature order is that of the host, unless set by setQuadratureOrder().

static void integratePolytopes(const MeshType& mesh, const PolytopesType& polytopes, const DOFsType& dofs, Index vdim, const StateViewType& state, const DeviceLawType& law, const ::Kokkos::View<Real*, MemorySpace>& values, size_t offset, Real sign, bool accumulate, const ::Kokkos::View<Index*, MemorySpace>& indices)

Integrates the cells of at most Vertices vertices.

Template parameters
Vertices Maximum vertex count of the cells.
Parameters
mesh Mesh of the spaces.
polytopes Integrated polytopes, located by prepare().
dofs Device degrees of freedom of the test space.
vdim Vector dimension of the test space.
state Device coefficients of the current displacement.
law Device evaluation of the hyperelastic law.
values Entry values.
offset Position of the first entry.
sign Factor of the contributions.
accumulate Whether the contributions are added to the values instead of replacing them.
indices Entry indices, test degrees of freedom, written as the values unless empty.

Local index a * vdim + c is component c of the scalar degree of freedom a.
