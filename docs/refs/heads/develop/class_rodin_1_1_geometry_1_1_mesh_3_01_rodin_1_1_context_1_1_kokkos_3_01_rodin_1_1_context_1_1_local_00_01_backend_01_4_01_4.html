Architecture

This specialization implements MeshBase directly. Connectivity, vertices, attributes and geometric maps are owned Kokkos arrays in the context's memory space. Host meshes are temporary construction and file-format adapters only; no LocalMesh is retained. There is no upload lifecycle. Mutators execute on the selected execution instance and finish before returning. Device kernels borrow getDeviceView(), which contains no host objects. Coordinate changes invalidate host evaluation caches using the same flush semantics as the local mesh. Copies deep-copy resident arrays.

Legacy host iterators and reference-returning queries use the resident data through explicit transfers and the existing evaluation caches. Connectivity computation discovers entities on the device. Attribute and map tables grow lazily in resident memory, preserving existing local IDs. Identity and real P1 maps on all Rodin reference families are supported. Higher-order and custom maps are rejected. Geometry must remain unchanged during evaluation. Borrowed views expire when the owner is destroyed, moved from, or changed by mutation, load or assignment. The application initializes Kokkos before construction and finalizes it after all meshes and kernels have finished.

std::uint64_t getRevision() const

Gets the revision of the entities and of their attributes.

Returns Revision, current after the entity slots are synchronized.

Revisions are unique across meshes. A mesh gets a new one when it is built or assigned, when an attribute is set, when its connectivity is handed out for modification and when discovered entities get their slots, so that a cache computed from the entities can tell whether it still holds. Coordinates and transformations do not change it.
