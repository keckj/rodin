DevicePolytopes

Polytopes integrated by a device integrator and the position of their entries.

Defined in Rodin/Kokkos/Variational/Integral.h

  class Mesh>
class DevicePolytopes;
Template parameters
Mesh Resident Kokkos mesh type.

The polytopes are the cells of the mesh or its faces, as selected by the integration region. The quadrature tables and the attribute selection are uploaded on the first integration and again only when the mesh, the region, the quadrature orders or the selection change, so that repeated integrations do not allocate device memory. The entry offsets are located again only when the mesh revision, the region, the selection or the vector dimensions change, so that repeated integrations neither launch the counting kernels nor wait for them.

static size_t locate(const ExecutionSpace& execution, const Rodin::Kokkos::Geometry::MeshView& view, ::Rodin::Geometry::Region region, Index dimension, const AttributesType& attributes, const ::Kokkos::View<Index*, MemorySpace>& offsets, Index count, const TrialDOFs& trialDOFs, Index trialVDim, const TestDOFs& testDOFs, Index testVDim, size_t& spacing)

Computes the entry offsets of the polytopes.

Parameters
execution Execution space instance.
view Device mesh.
region Integration region.
dimension Dimension of the polytopes.
attributes Selected attributes; empty selects every polytope of the region.
offsets Entry offset of every polytope, written.
count Number of polytopes of the dimension.
trialDOFs Device degrees of freedom of the trial space.
trialVDim Vector dimension of the trial space.
testDOFs Device degrees of freedom of the test space.
testVDim Vector dimension of the test space.
spacing Set to the spacing of the entries.
Returns Number of entries.

A polytope owns the product of its trial and test local counts. When every integrated polytope owns the same count and there are more than one, the offset of a polytope is its rank among them and the spacing is their number, as described by getEntryPosition(). Otherwise the offset of a polytope is the count of the previous ones and the spacing is one.
