DeviceLayout

Arrangement of the entries of a device integrator.

Defined in Rodin/Kokkos/Variational/Integral.h

struct DeviceLayout;

Contents

  • Reference
    • Public functions

Integrators with equal layouts list the same coordinates in the same order, so their values can be summed entry by entry.
