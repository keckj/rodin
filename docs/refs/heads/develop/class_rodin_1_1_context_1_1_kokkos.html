Architecture

The distribution is the base subobject so existing distribution-facing Rodin interfaces remain available. The execution-space instance controls local kernel execution and transfers. Context copies share that execution association through Kokkos execution-space value semantics.

The application must initialize Kokkos before constructing this context and finalize it only after the context and its dependent allocations have been destroyed. The context does not initialize or finalize either runtime. CUDA, HIP or SYCL selection requires a Kokkos installation with that backend; execution never falls back to a host backend implicitly.
