KokkosKrylov

Device vectors and kernels of a Jacobi preconditioned Krylov solver on a Kokkos::SparseMatrix.

Defined in Rodin/Kokkos/Solver/Krylov.h

template <
  class Backend>
struct KokkosKrylov;
Template parameters
Backend Kokkos backend of the matrix.

Contents

  • Reference
    • Public types
    • Public static functions

The matrix is wrapped without copy. The right-hand side and the solution are copied between the host vectors of the system and device vectors, which are kept from one solve to the next while the size is unchanged.
