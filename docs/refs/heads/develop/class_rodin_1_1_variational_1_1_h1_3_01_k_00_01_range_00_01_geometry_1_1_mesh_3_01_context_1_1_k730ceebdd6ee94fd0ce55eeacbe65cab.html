The space pairs the H1 space of the resident shard, which numbers the local degrees of freedom of the kernels, with the distributed host H1 space, which numbers them across processes. Both spaces number the shard alike, since the resident shard keeps the polytopes of the host shard in the same order. The host members answer as the distributed host space does: getSize() is the global size, and getDOFs() and getGlobalIndex() return global indices. The device members, getDeviceDOFs() and getLocalSize(), refer to the local numbering.
