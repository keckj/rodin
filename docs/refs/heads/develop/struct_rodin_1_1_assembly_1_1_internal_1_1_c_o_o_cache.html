COOCache

Device buffers and sparsity pattern kept between the assemblies of a PETSc system.

Defined in Rodin/Kokkos/Assembly/PETSc.h

template <
  class MemorySpace>
struct COOCache;
Template parameters
MemorySpace Kokkos memory space of the buffers.

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions
    • Public variables

PETSc analyses the coordinate list in MatSetPreallocationCOO, which is much more expensive than MatSetValuesCOO. The pattern is kept to skip that analysis, and the coordinates are not even listed again, when the same matrix is assembled again with the same segments. PETSc is given the distinct coordinates sorted by row then column, which it analyses in linear time, and the values summed per coordinate on the device. Integrators restricted to attributes list their coordinates at every assembly, since the attributes of the cells may change. The buffers are reused while their size does not change.

A copy starts empty, so copies never share buffers.
