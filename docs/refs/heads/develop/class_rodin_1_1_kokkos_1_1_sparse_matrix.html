SparseMatrix

Sparse matrix in compressed row storage, resident in the memory space of a Kokkos backend.

Defined in Rodin/Kokkos/SparseMatrix.h

template <
  class Scalar,
  class Backend>
class SparseMatrix;
Template parameters
Scalar Coefficient type.
Backend Kokkos backend, as for Context::Kokkos.

Contents

  • Reference
    • Public types
    • Constructors, destructors, conversion operators
    • Public functions

The device assembly of a Problem builds it without copying the matrix to the host, so that a solver running on the device reads it in place. The columns of a row are sorted and unique. Copies are deep, as for Math::SparseMatrix; moves keep the storage.
