LinearSystem

Linear system with a Kokkos::SparseMatrix operator and host vectors.

The device assembly of a Problem fills the matrix in the memory of the backend, and a solver running on the device reads it there. The right-hand side and the solution stay on the host, where the grid functions keep their data. The constraints are eliminated during the assembly, so the system offers no elimination of its own.

A Problem assembles into this system when it is named in its template arguments:

using System = Math::LinearSystem<
  Rodin::Kokkos::SparseMatrix<Real, Backend>, Math::Vector<Real>>;
Problem<System, decltype(u), decltype(v)> poisson(u, v);
