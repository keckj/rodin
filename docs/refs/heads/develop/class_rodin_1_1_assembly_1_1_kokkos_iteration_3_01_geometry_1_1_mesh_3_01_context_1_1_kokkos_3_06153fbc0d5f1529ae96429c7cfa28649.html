Architecture

This descriptor follows the indexed contract of SequentialIteration and OpenMPIteration. It supplies a candidate count, an entity dimension, a region predicate and polytope access. Cells selects all maximal-dimensional entities. Faces, Boundary and Interface scan all codimension-one entities; Boundary accepts exactly one incident cell, and Interface accepts more than one, including nonmanifold adjacency. getCount() is the candidate count before filtering. Attribute selection remains an assembly concern.

Construction on the host retains scalar metadata and a private borrowed mesh handle. Capture this descriptor by value in a kernel on the mesh's execution space. filter() and getPolytope() access resident memory and must execute in that memory space; metadata access is also valid on the host. No incidence is computed and no mesh topology is downloaded. Nonempty Boundary and Interface traversal require explicitly materialized face-to-cell incidence. Face regions require positive mesh dimension.

The descriptor owns no mesh allocations. Finish kernels before mutating, moving or destroying the mesh, and reconstruct the descriptor afterward. Kernel scheduling and synchronization belong to the assembly backend.
