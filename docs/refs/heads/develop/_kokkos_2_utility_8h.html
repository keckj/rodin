void checkLaunches(const char* what)

Raises the launch error of a kernel launched since clearLaunches().

Parameters
what Name of the launched work, for the message.

Kokkos checks the launches only with its bounds checks enabled. A kernel refused at launch, for instance for lack of memory for its local arrays on a nearly full device, otherwise leaves its outputs unwritten without an error, and the assembled system silently misses its entries.

Define documentation

#define RODIN_KOKKOS_UNROLL

Unrolls the following loop completely when its trip count is static.

Kernel loops over the local basis functions have a static trip count when the polytope and the spaces are known at compile time. Unrolled, their local indices are constants, so the per-component structure of vector bases folds away and the local arrays stay in registers. The pragma is a no-op for a dynamic trip count and on compilers that do not support it.
