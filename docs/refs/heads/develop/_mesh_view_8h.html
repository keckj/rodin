Function documentation

Real getReferenceVertexCoordinate(::Rodin::Geometry::Polytope::Type type, Index a, Index d)

Gets a coordinate of a reference vertex.

Parameters
type Reference geometry.
a Local vertex index.
d Coordinate index.
Returns Coordinate of vertex , zero or one.

The reference vertices follow Rodin::Geometry::Polytope::Traits: the origin and the unit vectors on a simplex, the counterclockwise unit square or cube on a quadrilateral or hexahedron, the reference triangle extruded along on a wedge, and the unit square with the apex on a pyramid.
